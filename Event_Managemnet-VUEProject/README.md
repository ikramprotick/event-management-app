# 🎉 Event Management App (Vue 3)
A responsive Event Management web application built using Vue.js 3, Bootstrap 5, and Vue CLI. This project demonstrates component-based UI development, event listing, and a clean SPA structure.

## ✨ Features
- Event list UI  
- Responsive Bootstrap layout  
- Modular Vue components  
- Clean and simple project structure  
- Easy to customize and extend  

## 📌 Future Enhancements
- Add event creation form  
- Add search & filtering  
- Add backend API connection  
- Add authentication  
- Add calendar or schedule view

## 📦 Tech Stack
- Vue.js 3  
- Bootstrap 5  
- Vue CLI  
- JavaScript (ESNext)  
- ESLint + Babel  
- Node.js & npm

## 🚀 Project Setup
### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run serve
```

App runs at:
```
http://localhost:8080
```

### Build for production
```bash
npm run build
```

### Lint and fix files
```bash
npm run lint
```
